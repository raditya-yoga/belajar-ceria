# Belajar Ceria

Platform pembelajaran interaktif berbasis web untuk siswa kelas 1–3 SD yang dilengkapi materi pelajaran, latihan soal dengan pembahasan, sistem poin bintang, serta akses materi eksklusif berbasis langganan.

## Fitur Utama
- **Materi Kelas 1–3 SD:** Pembelajaran interaktif untuk 6 mata pelajaran dasar.
- **Kuis & Pembahasan:** Latihan soal interaktif dengan skor dan penjelasan jawaban.
- **Akun & Autentikasi:** Pendaftaran dan masuk akun pengguna untuk menyimpan progres belajar.
- **Akses Premium:** Pembukaan seluruh topik materi lanjutan dengan pembayaran QRIS terintegrasi.
